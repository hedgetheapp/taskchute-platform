# TaskChute Platform

TaskChuteをObsidian依存から独立させ、Serverを中核にAndroid・Widget・Obsidian等から利用できる個人向けTaskChute platformとして再設計するためのrepositoryです。

## Current status

- Status: Architecture / Bootstrap
- Runtime implementation: Not started
- Initial user model: Single-user, multi-device
- Target authority: TaskChute Server
- Android: first-class client
- Obsidian: future optional client / integration
- Notes: Markdown-native
- Images / attachments: architecture requirement

旧Obsidian実装は捨てず、移行元・現行利用・知識・回帰試験のreferenceとして残します。
