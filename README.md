# TaskChute Platform

TaskChuteをObsidian依存から独立させ、Serverを中核にWeb・Android・Wear OS・Obsidian等から利用できる個人向けTaskChute platformとして再設計するためのrepositoryです。

## Current status

- Status: Architecture / Bootstrap
- Runtime implementation: Not started
- Initial user model: Single-user, multi-device
- Target authority: TaskChute Server
- Web: primary / universal client、initial development priority最優先
- Android: native first-class client
- Wear OS / Pixel Watch: companion client target
- iOS native: future / low priority。まずWeb clientから利用
- Obsidian: future optional client / integration
- Notes: Markdown-native
- Images / attachments: architecture requirement

旧Obsidian実装は捨てず、移行元・現行利用・知識・回帰試験のreferenceとして残します。
